# 11. Frontend Architecture & Research Dashboard

## Frontend Architecture

Build two major interfaces.

### A. Virtual Hospital (3D Hospital)

Used for:

- Simulation
- Agent visualization
- Patient movement
- Department interaction
- Real-time events

### B. Clinical/Research Dashboard

Used for:

- Cases
- Reports
- Agent performance
- Physician reviews
- Training
- Evaluation
- Analytics

## Research Dashboard

Create a separate analytics section. Show:

- Overall Agent Accuracy
- Diagnostic Accuracy
- Safety Score
- Average Actions / Case
- Average Time / Case
- Physician Approval Rate
- Report Quality
- Improvement Across Versions

And graphs, e.g.:

```
Agent v0.1 → 62%
Agent v0.2 → 71%
Agent v0.3 → 79%
Agent v0.4 → 84%
```

This becomes powerful evidence for the research project.
