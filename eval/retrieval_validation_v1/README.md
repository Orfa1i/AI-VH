# Retrieval Validation v1 (PENDING physician review)

- **Pairs**: 40 (10 queries x top-4 semantic-hybrid candidates)
- **Status**: every label is `pending physician review`. DO NOT tune any
  threshold on this set until the owner approves the labels.
- **Review instructions**: for each pair, mark `relevance` as `relevant`
  or `not-relevant`; corrected labels go to `labels.approved.jsonl`.
- **Metric plan**: precision@k / recall@k across thresholds
  {0.0, 0.01, 0.05, 0.1} on the cosine-similarity scale [0, 1].
- **Provenance**: generated by `scripts/prepare_retrieval_validation_set.py`
  with Phase 1 `HarrisonAdapter` (semantic-hybrid, all-MiniLM-L6-v2).
