AI Virtual Hospital — Full Project Plan
1. Project Vision

Build a 3D Virtual Hospital Simulation Environment populated by autonomous AI agents representing:

Doctors
Nurses
Patients
Radiologists
Laboratory staff
Reception/administrative staff
Potentially pharmacists and other clinical roles later

The hospital should behave like a simulated healthcare environment where AI agents interact with each other, patients arrive with medical conditions, doctors investigate and diagnose them, nurses perform clinical workflows, and the system generates complete clinical reports.

The central research objective is:

Can autonomous medical AI agents improve their clinical decision-making and workflow behavior through expert human feedback and Reinforcement Learning?

The system should therefore contain a continuous loop:

Patient → Clinical Encounter → Agent Decisions → Diagnosis/Report → Human Physician Review → Feedback → Training/Evaluation → Improved Agent

4. How the 3D Hospital Should Work

The 3D environment is primarily the simulation and visualization layer.

It should NOT contain the medical intelligence itself.

For example:

3D Doctor
    ↓
Agent ID: doctor_001
    ↓
Doctor Agent Backend
    ↓
Clinical reasoning
    ↓
Tools
    ↓
EHR / Lab / Radiology

The character you see walking around is simply the embodied representation of an AI agent.

The agent's actual intelligence lives in the backend.

14. Case Complexity

You specifically want to measure how well the agents handle difficult cases.

Therefore create case levels.

Level 1 — Simple

Clear symptoms and diagnosis.

Level 2 — Moderate

Multiple possible diagnoses.

Level 3 — Complex

Multiple symptoms and comorbidities.

Level 4 — Difficult

Conflicting evidence.

Level 5 — High complexity

Multiple conditions, incomplete information, changing vitals and possible complications.

This creates a measurable benchmark.

Reward

The reward function evaluates the quality of the decision.

For example:

Correct diagnosis           + reward
Appropriate test            + reward
Unnecessary test            - penalty
Missed critical condition   - large penalty
Unsafe treatment            - large penalty
Good clinical report        + reward
Appropriate escalation      + reward

The reward design needs to be clinically validated.

32. Evaluation System

You need a formal evaluation framework.

Measure:

Diagnostic accuracy

Did it reach the correct diagnosis?

Differential diagnosis quality

Did it consider relevant alternatives?

Investigation quality

Did it order appropriate tests?

Treatment quality

Was the treatment appropriate?

Safety

Did it miss dangerous conditions?

Efficiency

How many unnecessary actions did it perform?

Time

How long did it take?

Report quality

Was the final report complete and clinically coherent?

Evidence grounding

Did its claims correspond to retrieved references?

33. Benchmark Dataset

Create a controlled set of cases.

For example:

100 cases
├── 20 easy
├── 30 moderate
├── 30 complex
└── 20 highly complex

Keep a held-out test set that agents never train on.

This is critical.

Otherwise you won't know whether the model actually learned.

A research/simulation environment, not a real clinical decision-making system.

Synthetic patients

Human oversight

49. The Most Important Research Experiment

The strongest experiment isn't:

"Can AI diagnose patients?"

Instead, make the research question:

"Can a multi-agent clinical AI system improve its decision-making and workflow performance through iterative expert feedback within a simulated hospital environment?"

Then compare:

Experiment A

Base MedGemma agent.

Experiment B

MedGemma + specialty RAG.

Experiment C

MedGemma + RAG + tools.

Experiment D

MedGemma + RAG + tools + multi-agent environment.

Experiment E

MedGemma + RAG + tools + multi-agent environment + human feedback/RL.

Then measure performance at every stage.

That gives you a scientifically meaningful progression rather than simply building a flashy AI hospital.

The key principle

Don't build the 3D hospital first.

Build the clinical simulation loop first:

Patient → Nurse → Doctor → Investigation → Diagnosis → Report → Physician Review → Feedback → Evaluation

Once that loop works reliably, put the 3D hospital around it.

That approach dramatically reduces the risk of spending months building a beautiful virtual hospital before proving that the AI-agent + clinical-feedback + learning loop actually works.
